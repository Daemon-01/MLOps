# MLOps Practicals & Projects

This repository contains practical assignments and implementations for the MLOps coursework.

## Structure

- `PO1(S24cseu1345).ipynb`: Practical 01 - Reproducibility, environment management, and run tracking.
- `P02-first-model/`: Practical 02 - First model training, evaluation, and delivery time prediction.
- `work/`: Work artifacts, requirement files, and run logs.
- `pyproject.toml` / `uv.lock`: Project dependencies and lockfiles.

## Setup & Requirements

Using `uv` or `pip`:

```bash
uv sync
```
or
```bash
pip install -r work/requirements.txt
```
